# 画像編集 (sdo-edit-pic)

Windows向けの画像編集ソフト。現状はJPG/PNG相互変換機能を提供する。

## 動作環境

- Windows 10 / 11

## 使い方

1. `画像編集.exe` をダブルクリックして起動する。
2. 「画像を選択...」ボタンをクリックし、編集したいPNGまたはJPG画像を選ぶ。
3. 画像上をドラッグして範囲を選択するとトリミングでき、「適用」ボタンで結果を反映する（「キャンセル」で選択を取り消せる）。適用後も続けて別の範囲をトリミングするなど、編集を重ねられる。
4. JPEG品質スライダーで、JPEGとして保存する際の品質を調整できる。
5. 「保存...」ボタンをクリックすると、その時点の編集結果を独立したファイルとして書き出せる。保存先は `%APPDATA%\sdo-edit-pic\` フォルダに、元のファイルと同じ名前で拡張子だけ変わった状態で保存される。画面には保存先のフルパスが表示される。
6. 「1つ前に戻す」で直前の編集を1つ取り消し、「最初の画像に戻す」で読み込み直後の状態まで一括で取り消せる（保存とは独立した操作で、保存しなければファイルには影響しない）。

## 注意事項

- 透過PNGをJPEGに変換すると、透明部分は白背景に変換される。
- 変換先に同名のファイルが既に存在する場合は上書きされる。
- 日本語を含むファイル名・フォルダ名にも対応している。
- 日本語フォント（游ゴシック / メイリオ / MSゴシックのいずれか）がシステムに見つからない場合、UIの日本語文字が正しく表示されないことがある。
