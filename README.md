# 画像編集 (sdo-edit-pic)

Windows向けの画像編集ソフト。現状はJPG/PNG相互変換機能を提供する。

## 動作環境

- Windows 10 / 11

## 使い方

画面は、左の「画像エリア」と右の固定幅の「操作パネル」に分かれている。画像は画像エリアの中央に表示され、どの編集モードに切り替えても画像の位置・大きさは変わらない（ウィンドウサイズを変えたときだけ追従する）。ボタン・入力欄・メッセージはすべて操作パネルに表示される。

1. `画像編集.exe` をダブルクリックして起動する。
2. 「画像を選択...」ボタンをクリックし、編集したいPNGまたはJPG画像を選ぶ。
3. 操作パネルに「修正したい項目をえらんでください」と表示されるので、「トリミング」か「モザイク」を選ぶ。選んだ項目の編集が終わる（「適用」または「キャンセル」）と、この項目選択の画面に戻る。適用後も続けて別の編集を重ねられる。
   - 「トリミング」: 方式を「自由選択」「サイズ指定」「画面比率」から選べる（最初は自由選択）。「自由選択」は画像上のドラッグで範囲を指定する（ドラッグで範囲を決めると、元画像上に枠が出て枠外が暗くなる。切り出し後の画像ではない。「適用」で確定する）。「サイズ指定」は幅・高さ(px)を入力すると固定サイズの枠が表示され、枠をドラッグして位置を決める（枠外は暗く表示。画像より大きい値は画像サイズに丸められる）。「画面比率」は比率（1:1, 4:3, 3:2, 16:9, 21:9, 3:4, 2:3, 9:16, 9:21）を選ぶと、その比率で画像に収まる最大の枠が中央に表示される。幅(px)を入力すると高さは比率から自動で決まり、枠をドラッグして位置を決める。範囲が決まったら「適用」で反映する。
   - 「モザイク」: 画像上をドラッグしてなぞった範囲にモザイクをかける。「モザイクの粗さ」「ブラシの太さ」をスライダーで調整でき、「1手戻す」で直前のなぞりを取り消せる。「適用」で反映する。
4. 「保存...」ボタンをクリックすると、その時点の編集結果を独立したファイルとして書き出せる。保存ダイアログは元画像のフォルダを開き、ファイル名の初期値は元のファイル名に `_cropped` を付けたもの（例: `photo.jpg` → `photo_cropped`）になる。拡張子はフィルタ選択で補われる。画面には保存先のフルパスが表示される。
5. 「1つ前に戻す」で直前の編集を1つ取り消し、「最初の画像に戻す」で読み込み直後の状態まで一括で取り消せる（保存とは独立した操作で、保存しなければファイルには影響しない）。

## 注意事項

- 透過PNGをJPEGに変換すると、透明部分は白背景に変換される。
- 変換先に同名のファイルが既に存在する場合は上書きされる。
- 日本語を含むファイル名・フォルダ名にも対応している。
- 日本語フォント（游ゴシック / メイリオ / MSゴシックのいずれか）がシステムに見つからない場合、UIの日本語文字が正しく表示されないことがある。
